4️⃣ بناء نظام Authentication و VIP حقيقي
━━━━━━━━━━━━━━━━━━

إنشاء نظام Authentication احترافي وآمن بالكامل يشمل:

* تسجيل حساب
* تسجيل دخول
* JWT Authentication
* Refresh Tokens
* Google Login OAuth

مع:

* تخزين المستخدمين داخل قاعدة بيانات حقيقية
* منع الاعتماد على localStorage للحماية
* استخدام HttpOnly Cookies للتوكنات الحساسة
* التحقق من الاشتراك من Backend فقط
* حماية صفحات VIP
* حماية APIs الخاصة
* منع أي تلاعب من المتصفح
* حماية Sessions بشكل كامل

ويجب تنفيذ:

* RBAC Authorization System
  (Role-Based Access Control)

لدعم الصلاحيات التالية:

* User
* VIP
* Admin

ويجب أن يتم التحقق من جميع الصلاحيات من خلال Backend فقط وليس Frontend.

⭐ مميزات الـ VIP
━━━━━━━━━━━━━━━━━━

يجب أن يحتوي اشتراك VIP على مميزات حقيقية يتم حمايتها بالكامل من خلال Backend وليس Frontend فقط.

وتشمل:

خلي ال * AI Analyzer خاص بالمشتركين VIP فقط 
* تلخيص وتحليل الأخبار المهمة تلقائيًا
* تحليل تأثير الأخبار على:

  * الأسهم
  * السوق
  * الاتجاه العام
* تنبيهات وتحليلات خاصة للمشتركين
* محتوى وتحليلات حصرية
* بيانات وأسواق متقدمة للمشتركين

ويجب:

* منع الوصول لهذه المميزات بدون اشتراك حقيقي
* التحقق من صلاحيات VIP في كل Request من خلال السيرفر
* منع فتح المميزات عبر DevTools أو التلاعب بالـ Frontend
* حماية جميع Endpoints الخاصة بالـ VIP Middleware حقيقي وآمن

كما يجب تنفيذ AI News Analyzer بشكل عملي وقابل للإدارة بدون استهلاك مبالغ فيه.

ويجب تحديد:

* آلية التحليل
* آلية التلخيص
* Limits للاستخدام
* Cache للنتائج
* إدارة التكلفة
* حماية النظام من الاستهلاك المفرط

5️⃣ نظام الدفع والاشتراكات
━━━━━━━━━━━━━━━━━━

تصميم وتنفيذ نظام اشتراكات ودفع احترافي وآمن وقابل للتوسع مستقبلًا.

مهم جدًا:

وسيلة الدفع الأساسية الحالية المتوفرة هي:

* Vodafone Cash فقط

لذلك يجب:

* بناء نظام الدفع الحالي بحيث يعتمد على فودافون كاش بشكل منظم وآمن
* تصميم Payment Architecture قابلة لإضافة وسائل دفع أخرى مستقبلًا بسهولة
* عدم ربط النظام الحالي مباشرة بمزود دفع واحد فقط
* تجهيز النظام لدعم Stripe مستقبلًا بدون إعادة بناء جذرية

ويجب إضافة:

* صفحة رفع إثبات الدفع
* ربط إثبات الدفع بحساب المستخدم
* Dashboard للإدارة لمراجعة المدفوعات
* Dashboard لتفعيل الاشتراكات بشكل موثق وآمن
* منع أي تفعيل يدوي عشوائي غير موثق
* تسجيل جميع عمليات الدفع والمراجعة داخل قاعدة البيانات

وفي حالة إضافة Stripe لاحقًا يجب أن يكون النظام جاهزًا لدعم:

* Subscription System
* Auto Renewal
* Payment Webhooks
* Automatic VIP Activation
* Failed Payments Handling
