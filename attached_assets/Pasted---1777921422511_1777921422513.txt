أحتاج منك مراجعة شاملة وإعادة بناء الأنظمة الداخلية في موقعي الحالي ليصبح جاهزًا للاستخدام الحقيقي والإطلاق. --- المشاكل الحالية في المشروع: 1. نظام الأخبار ضعيف الأخبار قليلة ومصادرها محدودة لا يتم الاعتماد على مصادر قوية أو متعددة 2. لا يوجد Backend حقيقي النظام يعتمد بالكامل على localStorage لا يوجد تحقق حقيقي من المستخدمين 3. نظام VIP غير آمن وضعيف عالج اي خطأ في نظام ال vip وضيف كل بيانات وتوصيات وكل شي حقيقي ومتخدث تلقاءيا وضيف ميزة الماسح الاسخم حقيقي زي موقع انفستزنج وكل حجاه خلي لها بيانات حقيقيه وضيف اخبار حصريه كمان يمكن لأي مستخدم التلاعب به من خلال المتصفح لا يوجد تحقق من السيرفر 4. مفاتيح API مكشوفة موجودة داخل الكود في Frontend مما يشكل خطرًا أمنيًا كبيرًا 5. لا يوجد نظام دفع حقيقي الدفع يتم يدويًا لا يوجد تفعيل تلقائي للاشتراكات 6. بيانات الأسواق غير حقيقية الأسعار ثابتة غير مرتبطة بأي مصدر بيانات مباشر --- المطلوب: 1. إصلاح نظام الأخبار: استخدام APIs حقيقية متعددة (مثل NewsAPI و Finnhub) دمج أكثر من مصدر لزيادة جودة وتنوع الأخبار ضمان عمل الأخبار بشكل مستقر بعد النشر --- 2. إنشاء Backend باستخدام Node.js: يكون مسؤول عن: جلب الأخبار إدارة المستخدمين التحقق من حالة الاشتراك (VIP) تصميم API منظم وقابل للتطوير --- 3. تأمين مفاتيح API: نقل جميع المفاتيح إلى environment variables أو secrets عدم ظهور أي مفتاح في Frontend نهائيًا --- 4. بناء نظام VIP حقيقي: نظام تسجيل دخول (Authentication) تخزين بيانات المستخدمين في قاعدة بيانات التحقق من الاشتراك من خلال Backend منع أي تلاعب من جهة المستخدم --- 5. دمج نظام دفع: استخدام Stripe تفعيل الاشتراك تلقائيًا بعد الدفع ربط الدفع بحالة VIP في النظام --- 6. ربط بيانات الأسواق: استخدام APIs حقيقية مثل: Finnhub Alpha Vantage عرض بيانات حقيقية محدثة باستمرار --- 7. الأمان (مهم جدًا): مراجعة المشروع بالكامل بحثًا عن أي ثغرات تأمين: API endpoints Authentication system البيانات الحساسة منع: التلاعب من المتصفح
